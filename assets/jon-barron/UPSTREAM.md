# Jon Barron academic website template

Source: https://github.com/jonbarron/jonbarron.github.io
Stylesheet: https://raw.githubusercontent.com/jonbarron/jonbarron.github.io/master/stylesheet.css
Retrieved: 2026-11-12.

The source repository README expressly permits cloning the code for personal use. This copy preserves the upstream styles, changing only font URLs to serve the same Lato fonts locally. No MIT license is asserted for the template. The homepage follows its HTML component structure, with a centered portrait and name following Lanxiang Hu’s adaptation at https://snyhlx.github.io/.

Lato font files are distributed under the SIL Open Font License; see `fonts/OFL.txt`. Research figures, personal content, and photographs are separate from the template.
